# Soccer Master

A web application built with ASP.NET Core MVC for managing soccer teams, players, and match records.

## Features
- User registration and login system with ASP.NET Core Identity (Role-based access)
- Full CRUD operations for team and player management
- Entity Framework Core Code-First approach for database management
- Clean UI constructed with Razor Views and ViewModels

## Technologies Used
- C#
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- MS SQL Server
- HTML, CSS, JavaScript, Bootstrap
- Git / GitHub
